## Featured Projects 💻

### [Game Servers}

**[Valheim Game Server]** is a PC & Xbox gaming server built with a headless Debian OS on an old Asus Laptop, it's running the server via LinuxGSM. This project demonstrates my ability to utilize Bash for terminal only configuring of installation procedures and network configuration.

**[EYE: Divine Cybermancy]** is another gaming server built for an older windows game; the server also uses a headless Debian instance on the same old Asus Laptop. It's running windows executive files via WINE and tmux.
